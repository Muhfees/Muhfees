## Quick Start

**Data Engineering:**
```bash
git clone https://github.com/Muhfees/data-pipeline-demo.git
cd data-pipeline-demo
python setup.py install
# See docs/README.md for full guide
```

**IoT Development:**
```bash
git clone https://github.com/Muhfees/iot-sensor-monitor.git
cd iot-sensor-monitor
pip install -r requirements.txt
# Upload firmware to Arduino/Raspberry Pi
```

**Flutter (Mobile):**
```bash
git clone https://github.com/Muhfees/time-tracker-app.git
cd time-tracker-app
flutter pub get
flutter run
```
